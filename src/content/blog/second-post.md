# Building with Astro

Astro has been an incredible framework for building fast, modern websites. Here's what I love about it:

## Performance First

Astro ships zero JavaScript by default, which means your site loads incredibly fast. You only add JavaScript when you need it.

## Component Islands

The islands architecture allows you to use any UI framework (React, Vue, Svelte) alongside vanilla HTML and CSS.

## Developer Experience

- Excellent TypeScript support
- Hot module reloading
- Great documentation
- Active community

## Conclusion

If you're looking for a modern static site generator that prioritizes performance, give Astro a try!
